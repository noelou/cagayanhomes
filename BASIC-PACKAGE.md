## Features to build

- [ ] Public pages: Home (banner, "Why work with me"), Buy, Rent, Property details, Contact, About me, header and footer
- [ ] Client stories shown across pages
- [ ] Mobile-friendly design
- [ ] Admin login: admin posts, edits and removes listings
- [ ] Property listing with info, featured image and photo gallery
- [ ] Photos auto-resized and converted to WebP
- [ ] Simple map: Google Map from the address or pasted coordinates
- [ ] Printable property details
- [ ] "List your property" inquiry form for owners (sent to admin)
- [ ] Seller's number hidden from the public, visible to admin only
- [ ] Filters: sell or rent
- [ ] Server setup (DigitalOcean, Nginx, Node.js, PostgreSQL), SSL, domain, backups
- [ ] Admin user guide and walkthrough

## Not in Basic (Standard / Full ra)

- Agent / owner registration and login
- Agents / owners mag-post sa ilang kaugalingong listings
- Admin approval sa listings
- Filters: location and price
- Admin notification kung naay bag-ong listing
- Interactive map pin picker

## Notes

- **Admin ra ang naay account.** Walay public register/login.
- Ang owners mo-send sa property details pinaagi sa **inquiry form o Facebook**, dayon ang admin ang mo-post sa listing.
- Ang seller number makita ra sa admin, dili sa public.
- Pwede pa mag-upgrade ang client later (Basic → Standard ₱13,000), so i-build nga dali ra madugangan sa Standard features.
- Sa `LEARNING.md` roadmap: ang **Phase 5** (register/login sa agents/owners) ug ang **admin approval** sa Phase 6 kay **dili apil sa Basic**. Admin login ra ang kinahanglan.
